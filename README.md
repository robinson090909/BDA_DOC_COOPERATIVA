# BDA_DOC_COOPERATIVA
Proyecto de Base de Datos para la gestión de documentos de una Cooperativa.
Realizado en MySQL Workbench.

## 📁 Archivos del proyecto

- *BDA DOC_COOPERATIVA.png* - Diagrama Entidad-Relación (DER)
- *doc_cooperativa.mwb* - Modelo en MySQL Workbench
- *script_cooperativa.sql* - Script SQL con la creación de la base de datos

## 🗃️ Tablas del sistema

1. SOCIO
2. CUENTA
3. TIPO_CUENTA
4. PRESTAMO
5. PAGO
6. EMPLEADO
7. SUCURSAL
8. DOCUMENTO
